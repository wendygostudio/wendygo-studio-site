# A focus shield should protect the block, not your whole browser

Blocking every distracting site sounds productive until the work itself needs research, documentation or a team chat. The useful version of a focus shield is narrower: protect the current Pomodoro block while leaving the context that makes the task possible.

A practical setup looks like this:

1. Define one observable outcome for the block.
2. Choose a duration you are likely to finish.
3. Add only the two or three sites that repeatedly pull you away.
4. Review the list during the break, not every few minutes.

The distinction matters because a shield is a focus aid, not a security boundary. If it blocks legitimate context, you will disable it. If it adds a small amount of friction to the sites you open automatically, it can help the work block win that first decision.
