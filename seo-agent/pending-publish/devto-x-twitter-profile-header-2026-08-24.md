X has two profile images that are easy to confuse: the profile picture next to your posts, and the header/banner across the top of your profile. They need different canvases and different crop decisions.

## The official dimensions

X recommends:

- **Profile picture:** 400×400 pixels, with a maximum file size of 2 MB.
- **Header/banner:** 1500×500 pixels.

X also warns that about 60 pixels at the top and bottom of a header can be cropped depending on the screen and browser. Keep faces, logos and essential text in the middle of the canvas. The official help pages list JPEG, GIF and PNG for profile photos.

The most reliable workflow is to start with the right canvas rather than resize a finished crop. Keep the profile image square even when the source is a portrait. For the header, use the full 3:1 canvas and treat the outer edges as expendable.

## A local crop workflow

1. Choose 400×400 or 1500×500 before opening the source.
2. Set the focal point manually instead of accepting a blind center crop.
3. Keep text and faces away from the header's top and bottom edges.
4. Export, then inspect the file at its final size on both a wide and narrow viewport.

FrameForge can do this locally in Chrome, which is useful when you need several versions without sending the source image to a resizing service. The same principle applies to any image tool: verify its current permissions and privacy disclosure before installing it.

Profile images are not post images. X's current help says a single photo with a standard aspect ratio between 2:1 and 3:4 can display in full. If you need a repeatable wide 16:9 post export, use a separate canvas and check the live composer; 1200×675 is a practical preset, not a universal guarantee for every client.
