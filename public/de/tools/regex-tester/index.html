Häufig gestellte Fragen

Welche Regex-Variante verwendet dieses Tool?

Es verwendet die native Regex-Engine (ECMAScript) von JavaScript, dieselbe, die auch in Chrome, Firefox und Node.js läuft – Muster, die Sie hier testen, verhalten sich also in Ihrem Code gleich.

Unterstützt es Regex-Flags wie g, i, m und s?

Ja, Sie können allgemeine Flags umschalten, um den globalen Abgleich, die Groß-/Kleinschreibung, den Mehrzeilenmodus und das Punkt-All-Verhalten zu testen.

Kann ich mit mehrzeiligem Text testen?

Ja, fügen Sie einen beliebigen Textblock in das Testzeichenfolgenfeld ein – Übereinstimmungen werden in Echtzeit hervorgehoben, während Sie das Muster oder den Text bearbeiten.

Werden meine Testdaten irgendwohin gesendet?

Nein, der Abgleich läuft vollständig in Ihrem Browser über das in JavaScript integrierte RegExp – es wird nichts an einen Server gesendet, sodass Tests sicher anhand von Protokollen oder privaten Daten durchgeführt werden können.

Regex-Kurzreferenz

Eine komprimierte Referenz für die am häufigsten verwendete reguläre Ausdruckssyntax. Alle Muster in diesem Tester folgen der ECMAScript-Regex-Engine von JavaScript.
