Bildgrößen für soziale Medien

Finden Sie praktische Voreinstellungen für Breite und Höhe für die Plattformen, auf denen Sie veröffentlichen. Durchsuchen Sie die Tabelle und kopieren Sie eine Dimension mit einem Klick.

PlattformVerwendenEmpfohlene Größe

Dies ist eine lokale Referenztabelle. Plattformspezifikationen können sich ändern; Überprüfen Sie eine kritische Kampagne mit der Plattform selbst.

Häufig gestellte Fragen

Lädt dieses Tool meine Bilder hoch?

Nein. Diese Seite ist eine Referenztabelle und wird in Ihrem Browser ausgeführt. Es wird weder ein Bild angefordert noch Daten irgendwohin gesendet.

Werden diese Abmessungen von jeder Plattform garantiert?

Dabei handelt es sich um praktische empfohlene Abmessungen und nicht um das Versprechen, dass eine Plattform ihre Spezifikationen niemals ändern wird. Schauen Sie vor einer kritischen Kampagne im Hilfecenter der Plattform nach.

Kann ich eine Dimension kopieren?

Ja. Verwenden Sie die Schaltfläche „Kopieren“ in einer beliebigen Zeile, um deren Breite und Höhe zu kopieren.

Welches Tool kann diese Bilder vorbereiten?

FrameForge kann die Größe von Bildern ändern und sie lokal mit sozialen Voreinstellungen exportieren.
