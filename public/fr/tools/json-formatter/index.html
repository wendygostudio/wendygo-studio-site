Comment utiliser ce formateur JSON

Collez n'importe quelle chaîne JSON dans le panneau de saisie. Cliquez Format pour l'embellir avec la coloration syntaxique et l'indentation choisie (2 ou 4 espaces). Cliquez Réduire pour compresser les espaces pour les charges utiles de production. Si le JSON n'est pas valide, le message d'erreur affiche la ligne et la colonne exactes où l'analyse a échoué afin que vous puissiez le corriger rapidement.

Coller JSON le formate automatiquement immédiatement – ​​aucun clic de bouton n’est nécessaire. Cliquez Copie pour copier la sortie propre dans votre presse-papiers. Tout s'exécute dans votre navigateur : aucune donnée n'est envoyée à un serveur, ce qui garantit la sécurité des réponses API, des fichiers de configuration et des données privées.

Questions fréquemment posées

Mes données JSON sont-elles téléchargées quelque part ?

Non. Le formatage, la validation et la réduction s'effectuent tous localement dans votre navigateur avec JavaScript. Rien de ce que vous collez n'est envoyé à un serveur, ce qui garantit la sécurité des réponses API, des fichiers de configuration et d'autres données privées.

Prend-il en charge les commentaires ou les virgules finales (JSON5) ?

Non, cet outil valide le JSON strict selon la spécification JSON. Les commentaires et les virgules de fin s'afficheront comme une erreur de syntaxe avec la ligne et la colonne exactes afin que vous puissiez les corriger ou les supprimer.

Quelle est la différence entre Formater et Réduire ?

Le format ajoute une indentation et des sauts de ligne pour plus de lisibilité. Réduisez tous les espaces pour produire la charge utile la plus petite possible pour une utilisation en production.

Y a-t-il une limite de taille pour le JSON que je peux coller ?

Il n'y a pas de limite stricte fixée par l'outil lui-même, mais des charges utiles très volumineuses (plusieurs Mo) peuvent ralentir le formatage puisque tout s'exécute dans l'onglet de votre navigateur plutôt que sur un serveur.
