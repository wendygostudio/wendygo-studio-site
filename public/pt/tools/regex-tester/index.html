Perguntas frequentes

Que sabor regex esta ferramenta usa?

Utiliza o motor regex nativo do JavaScript (ECMAScript), o mesmo que é executado no Chrome, Firefox e Node.js — pelo que os padrões aqui testados comportam-se da mesma forma no seu código.

Suporta sinalizadores regex como g, i, m e s?

Sim, pode alternar os sinalizadores comuns para testar a correspondência global, a insensibilidade a maiúsculas e minúsculas, o modo multilinha e o comportamento ponto-tudo.

Posso testar em texto multilinha?

Sim, cole qualquer bloco de texto no campo de cadeia de teste — as correspondências são destacadas em tempo real à medida que edita o padrão ou o texto.

Os meus dados de teste são enviados para algum lugar?

Não, a correspondência é executada inteiramente no seu browser através do RegExp integrado do JavaScript — nada é enviado para um servidor, pelo que é seguro testar em registos ou dados privados.

Referência rápida Regex

Uma referência condensada para a sintaxe de expressão regular mais utilizada. Todos os padrões neste testador seguem o motor regex ECMAScript do JavaScript.

SímboloSignificadoExemplo
.Qualquer caractere exceto nova linha (adicionar é sinalizador para corresponder às novas linhas)c.t. → "gato", "cortar"
\dQualquer dígito 0–9\d\d\d → "404"
\cCaracter de palavra [a-zA-Z0-9_]\c+ → "olá_mundo"
\sEspaço em branco (espaço, tabulação, nova linha)\s+ → lacunas entre palavras
\bLimite da palavra\bgato\b corresponde a "gato" e não a "apanhar"
^Início da string (ou linha com eu bandeira)^\d → linha que começa com um dígito
$Fim da string (ou linha com eu bandeira)\d$ → linha terminada com um dígito
*0 ou mais (ganancioso)ab* → "a", "ab", "abbb"
+1 ou mais (ganancioso)ab+ → "ab", "abbb" (e não "a")
?0 ou 1 (opcional)cor → "cor" ou "cor"
{n,m}Entre n e m vezes\d{2,4} → 2 a 4 dígitos
[abc]Classe de personagem (qualquer um de a, b, c)[aeiou] → qualquer vogal
[^abc]Classe negada (qualquer coisa menos a, b, c)[^\d] → não dígito
(abc)Grupo de captura — armazenado como $1, $2…(\d{4})-(\d{2}) → dois grupos
(?:abc)Grupo não capturador(?:foo|bar)baz
uma|bAlternação (a ou b)gato | cachorro
*? +?Quantificador preguiçoso (correspondência mais curta)<.+?> corresponde apenas à primeira etiqueta
