Perguntas frequentes

Esta ferramenta carrega as minhas imagens?

Não. Esta página é uma tabela de referência e é executada no seu browser; não solicita uma imagem nem envia dados para lado nenhum.

Estas dimensões são garantidas por cada plataforma?

São dimensões práticas recomendadas e não uma promessa de que uma plataforma nunca irá alterar as suas especificações. Verifique a central de ajuda da plataforma antes de uma campanha crítica.

Posso copiar uma dimensão?

Sim. Utilize o botão Copiar em qualquer linha para copiar a sua largura e altura.

Que ferramenta pode preparar essas imagens?

O FrameForge pode redimensionar e exportar imagens localmente com predefinições sociais.
