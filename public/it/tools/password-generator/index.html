Generatore di password

Crea password complesse e casuali con la lunghezza e i set di caratteri scelti. Tutto funziona nel tuo browser: nessun server, nessun account, niente inviato da nessuna parte.

Seleziona almeno un set di caratteri per generare una password.
Produzione

Cosa rende una password complessa?

La forza della password viene misurata entropia - il numero di bit necessari per indovinarlo con la forza bruta. Una password di 20 caratteri che mescola lettere maiuscole, minuscole, numeri e simboli ha circa 131 bit di entropia, rendendola effettivamente inviolabile con l'hardware attuale.

Come regola generale: utilizza almeno 16 caratteri, includi sempre più tipi di caratteri, non riutilizzare mai le password su più siti e archiviale in un gestore di password dedicato. Questo strumento utilizza crypto.getRandomValues() - lo stesso RNG crittografico utilizzato dal tuo browser per TLS - quindi ogni password generata qui è veramente casuale.

Minimo 16 caratteri Aggiunge esponenzialmente più combinazioni per ogni personaggio extra che aggiungi.
Mescola tutti i tipi di personaggi L'inclusione dei simboli aumenta il set di caratteri da 62 a ~94, moltiplicando l'entropia per carattere.
Una password per account Una violazione in un sito non può essere utilizzata su altri se ogni password è unica.
Utilizza un gestore di password Bitwarden, 1Password o il gestore integrato del tuo browser possono archiviarli e compilarli automaticamente in modo sicuro.

Domande frequenti

Le password generate vengono archiviate o inviate ovunque?

No. Le password vengono generate e visualizzate interamente nel tuo browser utilizzando crypto.getRandomValues(): nulla viene trasmesso a nessun server o registrato da nessuna parte.

Cosa rende sicura una password?

La lunghezza conta più dei trucchi complessi: punta ad almeno 16 caratteri mescolando maiuscole, minuscole, numeri e simboli. Ciò fornisce ben oltre 100 bit di entropia, che è effettivamente inattaccabile con l'hardware attuale.

Posso scegliere quali set di caratteri includere?

Sì, puoi configurare la lunghezza e alternare maiuscole, minuscole, numeri e simboli per soddisfare le regole della password specifiche di un sito.

È sicuro da usare per password bancarie o altre password sensibili?

Sì, la generazione avviene localmente utilizzando l'RNG crittografico del browser, lo stesso utilizzato per TLS. Come sempre, archivia il risultato in un gestore di password dedicato anziché riutilizzarlo su più siti.
