# Exportaciones de Chrome Web Store

Guarda aquí los CSV/XLSX oficiales del Developer Dashboard, fuera de `public/`.
Usa un archivo por extensión y periodo, por ejemplo:

`slimeforge-2026-08-13.csv`

Conserva impresiones de ficha, instalaciones, desinstalaciones, usuarios
activos, país/idioma y versión cuando estén disponibles. No introduzcas claves,
cookies ni capturas con datos privados.
