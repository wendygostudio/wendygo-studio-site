# Análisis competitivo — 2026-08-04

## Alcance

Revisión editorial de los clusters actuales frente a CyberChef, Canva, Forest,
CloudConvert y GoFullPage. No se usan estimaciones de volumen sin una lectura
actualizada de Search Console.

## Gaps útiles

1. **TextForge / CyberChef**: falta una comparación explícita de recetas de
   limpieza de texto, extracción de URLs y procesamiento local para tareas
   diarias. La base ya existe; conviene reforzar enlaces entre esas guías antes
   de crear otra URL.
2. **FrameForge / Canva**: existe cobertura de miniaturas y recortes, pero se
   puede mejorar la explicación de privacidad y exportación local frente a
   editores que suben imágenes.
3. **SlimeForge / Forest**: la diferencia de mascota, sesiones que progresan y
   Focus Shield está documentada; falta una medición estable de activación para
   saber qué propuesta genera instalaciones.
4. **ConvertForge / CloudConvert**: el posicionamiento local-first está claro,
   pero la demanda debe validarse antes de crear más comparativas.

## Decisión

No se crea una página pilar ni un artículo nuevo esta semana. La acción de más
impacto es reforzar enlazado interno y medir las fichas de SlimeForge,
FrameForge y ClaimForge con datos de dos semanas completas.
