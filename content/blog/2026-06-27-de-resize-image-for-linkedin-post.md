# So ändern Sie die Größe eines Bildes für LinkedIn-Beiträge in Chrome (1200 x 627)

LinkedIn rendert Feed-Bilder mit einem schmalen horizontalen Ausschnitt, ähnlich wie X und Facebook. Quadratische Fotos verlieren die vertikalen Kanten. Porträtaufnahmen werden gequetscht. Die Lösung: Posten Sie mit 1200 x 627 Pixel (ungefähr 1,9:1) und das Bild wird in der Vorschau des LinkedIn-Feeds vollständig angezeigt, ohne unerwartete Beschneidungen.

## Anforderungen an die Bildgröße von LinkedIn

| Property | Value |
|----------|-------|
| Recommended size | 1200×627 px |
| Aspect ratio | ~1.9:1 (approximately 16:8.4) |
| Max file size | 10 MB (JPG/PNG) |
| Accepted formats | JPG, PNG, WebP |

## Warum LinkedIn Bilder beschneidet

LinkedIn wendet beim Rendern von Inline-Bildern in Ihrem Feed einen Mittelzuschnitt an. Die Plattform zeigt ungefähr einen 1,9:1-Ausschnitt von der Mitte dessen, was Sie anbringen.

Ein quadratisches (1:1) Foto mit 1200 x 1200 wird auf etwa 1200 x 627 zugeschnitten, wobei das obere und untere Drittel abgeschnitten wird. Eine Porträtaufnahme (9:16) wird noch aggressiver in der Mitte beschnitten und zeigt in der Vorschau nur einen dünnen vertikalen Ausschnitt.

Durch das Posten bei 1200×627 wird die Nichtübereinstimmung beseitigt. Ihr Bild hat bereits die richtigen Proportionen für den LinkedIn-Feed, sodass in der Vorschau die vollständige Komposition ohne unerwartete Beschnitte angezeigt wird.

## Ändern Sie die Größe für LinkedIn mit FrameForge

1. **Installieren Sie FrameForge** – Laden Sie es aus dem Chrome Web Store herunter und heften Sie es an Ihre Symbolleiste.
2. **Öffnen Sie Ihr Bild** – Klicken Sie auf das FrameForge-Symbol und dann auf **Bild öffnen** oder ziehen Sie Ihre Datei per Drag-and-Drop auf die Leinwand.
3. **Wählen Sie die LinkedIn-Voreinstellung aus** – Wählen Sie im Dropdown-Menü **Plattform** die Option **LinkedIn-Beitrag** aus. Die Leinwand ist auf 1200 x 627 Pixel festgelegt.
4. **Passen Sie den Zuschnitt an** – Ziehen Sie die Zuschneideüberlagerung, um Ihr Motiv im Rahmen zu zentrieren. Sehen Sie sich beide Füllmodi in der Vorschau an, um zu sehen, welcher für Ihr Bild am besten aussieht.
5. **Exportieren** – Klicken Sie auf **Exportieren**. FrameForge speichert das in der Größe 1200×627 geänderte Bild in Ihrem Download-Ordner – bereit zum Hochladen auf LinkedIn.

## Welcher Füllmodus für LinkedIn?

**Zum Ausfüllen zuschneiden** (empfohlen) – Die gesamte 1200×627-Leinwand ist ausgefüllt; Überschüsse an den Seiten (für Hochformatquellen) oder oben/unten (für Querformatquellen) werden abgeschnitten. Entscheiden Sie genau, was im Rahmen bleibt, indem Sie die Überlagerung ziehen.

**Mit Polsterung anpassen** – Das vollständige Quellbild ist sichtbar, wobei Balken den 1200×627-Rahmen ausfüllen. In einem professionellen Feed sieht das oft unbeabsichtigt aus.

**Zum Füllen strecken** – Das Bild wird horizontal verzerrt. Vermeiden Sie es, es sei denn, Sie haben sich bewusst für eine Verzerrung entschieden.

## LinkedIn im Vergleich zu anderen Plattformen

Wenn Sie auf mehreren Plattformen posten, verarbeitet FrameForge alle. LinkedIn (1200×627, 1,9:1) unterscheidet sich geringfügig von X/Twitter (1200×675, 16:9) und Instagram (1080×1080, 1:1). Sie können eine LinkedIn-Version exportieren und dann die Voreinstellungen für die anderen Plattformen wechseln – gleiche Bildquelle, unterschiedliche Exporte, eine Erweiterung.
