# Como redimensionar uma imagem para publicações do Instagram no Chrome (1080×1080)

O seu telefone dispara às 9h16. O padrão do feed do Instagram é quadrado 1:1. Esta lacuna é onde os retratos ficam mutilados – rostos cortados na testa, detalhes importantes empurrados para a borda ou a imagem inteira espremida numa caixa de correio feia.

A correção não deve exigir o Photoshop ou o carregamento da sua fotografia para um site de terceiros. O FrameForge é uma extensão do Chrome que redimensiona as imagens inteiramente no seu browser – sem upload, sem conta, sem espera por um servidor.

## Requisitos de tamanho de imagem do Instagram

| Format | Dimensions | Aspect ratio |
|--------|-----------|--------------|
| Square post | 1080×1080 px | 1:1 |
| Portrait post | 1080×1350 px | 4:5 |
| Landscape post | 1080×566 px | 1.91:1 |
| Minimum width | 1080 px | — |
| Max file size | 8 MB | — |
| Formats | JPG, PNG | — |

O Instagram comprime as imagens no upload, por isso comece com a versão da mais alta qualidade que tem. Trabalhar a partir de uma fonte comprimida ou de baixa resolução será visivelmente pior depois de a compressão do Instagram ser executada sobre ela.

## Porquê utilizar uma extensão de browser em vez de uma ferramenta online

Os redimensionadores Web – Canva, Adobe Express, Squoosh – funcionam, mas todos eles carregam a sua imagem para um servidor remoto. Para fotos pessoais, trabalho de cliente ou qualquer coisa que prefira manter privado, esta é uma verdadeira compensação.

**O FrameForge permanece local.** É executado como uma extensão do Chrome e processa a sua imagem utilizando os recursos da sua própria máquina. Nada é enviado para qualquer servidor — nem mesmo para telemetria. Não há nenhuma conta para criar e nenhum limite de tamanho de ficheiro imposto por uma quota de back-end.

Também funciona mais rápido do que as ferramentas web para ficheiros grandes, uma vez que não há latência de upload para aguardar.

## Passo a passo: Redimensionar para o Instagram com o FrameForge

1. **Instale o FrameForge** — Instale a partir da Chrome Web Store e fixe o ícone na sua barra de ferramentas no menu Extensões.
2. **Abra a sua imagem** — Clique no ícone do FrameForge e, em seguida, clique em Abrir imagem ou arraste o seu ficheiro diretamente para o ecrã.
3. **Selecione a predefinição de publicação no Instagram** — No menu suspenso Plataforma, selecione Publicação no Instagram. O ecrã é bloqueado a 1080×1080 px com uma proporção de 1:1.
4. **Ajuste o corte** — Arraste a sobreposição de corte para centrar o motivo. Alterne entre os modos de preenchimento para comparar a forma como cada um lida com a sua imagem específica.
5. **Exportar** — Clique em Exportar. O FrameForge guarda a imagem 1080×1080 na sua pasta Downloads, pronta para upload.

## Tratamento de fotos de retrato e paisagem

A maioria das publicações do Instagram começa como fotografias verticais de telefone – proporção de 9:16 a entrar numa moldura quadrada de 1:1. O FrameForge oferece três formas de lidar com isso:

**Cortar para preencher** (recomendado): o quadro é preenchido na totalidade. O excesso de cima e de baixo é cortado. Arraste a sobreposição para decidir o que permanece no enquadramento — geralmente centrado no rosto do sujeito ou no aspeto principal.

**Ajuste com preenchimento**: toda a imagem é visível, mas aparecem barras horizontais nas laterais. Pode parecer intencional se as barras tiverem uma cor deliberada, mas geralmente parece uma reflexão tardia no Instagram.

**Alongar para preencher**: a imagem é distorcida horizontalmente para preencher o enquadramento. Quase sempre parece mau – evite-o, a menos que a distorção seja uma escolha estilística deliberada.

Para fotos de paisagem (amplas) que vão para um quadrado: o excesso está à esquerda e à direita. A mesma lógica se aplica – corte para preencher e ajuste a sobreposição para manter o assunto principal centrado.

## Qual o formato de publicação do Instagram que deve escolher?

Todos os três formatos funcionam no Instagram, mas têm comportamentos diferentes no feed:

**Quadrado (1:1)** é a escolha mais segura. Funciona de forma consistente na visualização em grelha, na página de exploração e no feed inicial. Se estiver a publicar em várias plataformas simultaneamente, o corte quadrado é o mais portátil.

**Retrato (4:5)** ocupa mais espaço vertical no feed — cerca de 20% mais espaço no ecrã do que um quadrado. Para fotos que já estão na vertical, este formato permite mostrar mais da imagem sem cortar de forma tão agressiva. O FrameForge pode lidar com isto com uma proporção de corte personalizada.

**Paisagem (1,91:1)** ideal para fotos panorâmicas e composições amplas. Mostra menos imagem na visualização do feed, mas pode funcionar bem para cenas em que a largura é mais importante do que a altura.

## Redimensionamento para múltiplas plataformas

Se publicar o mesmo conteúdo no YouTube, Twitch ou X, o FrameForge inclui predefinições para todos eles. Pode redimensionar a mesma imagem de origem para diferentes dimensões de plataforma sem trocar de ferramentas – útil para fluxos de trabalho em lote ao publicar em canais no mesmo dia.

## Perguntas frequentes

**Qual é o tamanho de imagem correto para uma publicação no Instagram?**
1080×1080 px para uma coluna quadrada (proporção 1:1). O Instagram também suporta retrato (1080×1350, 4:5) e paisagem (1080×566, 1,91:1). O Square é o mais seguro se não tiver a certeza de qual usar.

**O FrameForge carrega as minhas imagens para um servidor?**
Não. O FrameForge processa tudo localmente no seu browser. Nada é carregado e não é necessária qualquer conta.

**E se a minha foto estiver na orientação retrato (vertical)?**
Utilize o corte para preencher – O FrameForge permite arrastar a sobreposição de corte para manter a parte importante da sua fotografia no enquadramento 1080×1080, aparando a parte superior e inferior.

**Posso utilizar o FrameForge para outras plataformas?**
Sim. Inclui predefinições para miniaturas do YouTube (1280×720), painéis Twitch e tamanhos de publicação X (Twitter), para que possa redimensionar a mesma imagem para diferentes plataformas sem alterar as ferramentas.

**O FrameForge é gratuito?**
Sim – instalação gratuita com redimensionamento principal e predefinições de plataforma incluídas. Uma atualização Pro adiciona sobreposição de texto e processamento em lote.
