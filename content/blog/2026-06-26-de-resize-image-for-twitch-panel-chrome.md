Unterhalb deiner Kanalbiografie befinden sich Twitch-Panels – kleine rechteckige Kästchen, in denen Streamer Miniaturansichten, Call-to-Actions und Quicklinks platzieren. Sie haben eine Größe von 320 x 160 Pixel, was eines der schwierigsten Seitenverhältnisse ist, mit denen man arbeiten kann. Die meisten Bildbearbeitungsprogramme gehen von quadratischen oder breiten Formaten aus. Ein Quellfoto, das im 16:9-Format gut aussieht, wird verstümmelt, wenn Sie versuchen, es in ein ultrabreites 2:1-Rechteck zu quetschen.

Diese Anleitung zeigt, wie Sie die Größe von Bildern für Twitch-Panels mithilfe von **FrameForge** ändern, einer Chrome-Erweiterung, die die Mathematik für Sie übernimmt und Ihre Bilder lokal hält (kein Hochladen auf einen Server).

## Abmessungen des Twitch-Panels

| Property | Value |
|----------|-------|
| **Panel size** | 320×160 px |
| **Aspect ratio** | 2:1 (ultra-wide) |
| **Max file size** | 10 MB |
| **Formats** | JPG, PNG, GIF, WebP |
| **Number of panels** | Up to 3 rows (unlimited, but only 3 visible per row) |

Panels werden im Kanaldesign oft übersehen, aber sie sind das Erste, was ein Besucher nach Ihrem Header-Bild sieht. Ein schlecht zugeschnittenes Panel sieht unvollendet aus.

## Die Cropping-Herausforderung

Ein 2:1-Rechteck schneidet vertikal viel ab. Wenn Sie ein Porträtfoto (9:16) oder sogar ein 3:4-Porträtfoto haben, zeigt der Panelrahmen nur einen dünnen horizontalen Ausschnitt. Landschaften (16:9) sind näher beieinander, erfordern aber dennoch eine bestimmte Bepflanzung, um toten Raum zu vermeiden.

**FrameForge enthält eine Twitch-Panel-Voreinstellung**, sodass Sie die Abmessungen nicht manuell berechnen oder mit Zuschneideverhältnissen experimentieren müssen. Laden Sie Ihr Bild, wählen Sie die Voreinstellung aus und passen Sie die Zuschneideüberlagerung an.

## Schritt-für-Schritt: Größe für Twitch-Panels mit FrameForge ändern

1. **Installieren Sie FrameForge** aus dem Chrome Web Store. Heften Sie das Symbol an Ihre Symbolleiste an.

2. **Öffnen Sie Ihr Bild.** Klicken Sie auf das FrameForge-Symbol und dann auf **Bild öffnen** oder ziehen Sie Ihre Datei auf die Leinwand.

3. **Wählen Sie im Dropdown-Menü „Plattform“ das Twitch-Panel aus.** Die Leinwand wird sofort auf 320×160 Pixel eingestellt.

4. **Passen Sie den Zuschnitt an.** Ziehen Sie die Überlagerung, um den Teil Ihres Bildes einzurahmen, der am wichtigsten ist – Ihr Gesicht, Ihr Logo oder das wichtigste visuelle Element. Mit FrameForge können Sie den Zuschnitt live sehen.

5. **Exportieren.** Klicken Sie auf **Exportieren**. FrameForge speichert das in der Größe geänderte Bild in Ihrem Download-Ordner und kann es in die Einstellungen Ihres Twitch-Kanals hochladen.

## Warum Panels auf Twitch wichtig sind

Panels sind anpassbare Felder, in denen Sie verlinken können zu:
- Ihr Discord-Server
- Ko-Fi oder Patreon
- Stream-Zeitplan oder soziale Medien
- Ein Portfolio oder Linktree

Jedes Panel ist klein, aber zusammen füllen sie den Raum unter der Kopfzeile Ihres Kanals aus. Besucher sehen sie, bevor sie viel anderes sehen. Ein gestochen scharfes, gut zugeschnittenes Panel-Bild sieht professionell aus. Eine gestreckte oder außermittige Ernte wirkt wie ein nachträglicher Einfall.

Da die Bahnen so schmal sind, müssen Sie oft enger zuschneiden, als Sie erwarten würden. Bei einem Foto, das im 16:9-Format ausgewogen aussieht, müssen die Kanten möglicherweise erheblich beschnitten werden, damit es im 2:1-Format funktioniert.

## Häufige Verwendungszwecke des Twitch-Panels

- **Kanallogo oder -symbol** – 320×160 eignet sich gut für eine leicht Letterbox-Version Ihres Logos
- **Soziale Links** – Text + Symbol (Discord, Twitter, Instagram)
- **Sponsoring oder Produkt** – Spielcover, Softwareschnittstelle, Merchandise-Foto
- **Zeitplan oder Countdown** – Textüberlagerung auf einem einfarbigen Hintergrund (obwohl FrameForge keinen Text hinzufügt; das würden Sie in einem anderen Tool tun)

## Ist FrameForge kostenlos?

Ja. FrameForge kann kostenlos im Chrome Web Store installiert werden. Die kostenlose Version enthält die Twitch-Panel-Voreinstellung und alle wichtigen Tools zur Größenänderung. Eine Pro-Version fügt Textüberlagerung und Stapelverarbeitung hinzu, aber für die Größenänderung einzelner Bilder ist die kostenlose Version alles, was Sie brauchen.

**FrameForge verarbeitet alles in Ihrem Browser.** Ihr Bild berührt niemals einen Server. Kein Konto erforderlich. Keine Datenerfassung.
