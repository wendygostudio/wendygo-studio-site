Der Algorithmus von Pinterest bevorzugt vertikale Pins. Wenn Sie Bilder für die Plattform anpassen, konkurrieren Sie mit Tausenden anderen Pins um Platz in den Feeds der Benutzer – und die falschen Abmessungen werden beschnitten oder gestreckt.

Die Standardgröße für Pinterest-Pins beträgt **1000×1500 px** (Seitenverhältnis 2:3). Einige Ersteller verwenden 1000×1200 Pixel oder 1000×1300 Pixel, aber das 1000×1500-Format wird sowohl auf Mobil- als auch auf Desktop-Feeds ohne automatisches Zuschneiden perfekt angezeigt.

## Der schnellste Weg: FrameForge

FrameForge ist eine kostenlose Chrome-Erweiterung, die die Größe von Bildern ändert, ohne sie irgendwo hochladen zu müssen. Öffnen Sie ein beliebiges Foto oder einen Screenshot, wählen Sie die Pinterest-Voreinstellung aus, passen Sie den Zuschnitt an und exportieren Sie – alles in Ihrem Browser in weniger als einer Minute.

**Schritt 1: Installieren Sie FrameForge.** Fügen Sie es aus dem Web Store zu Chrome hinzu. Es dauert 10 Sekunden und erfordert kein Konto.

**Schritt 2: Klicken Sie auf das Erweiterungssymbol.** Wählen Sie „Bild öffnen“ und wählen Sie das Foto oder den Screenshot aus, dessen Größe Sie ändern möchten.

**Schritt 3: Wählen Sie die Pinterest-Voreinstellung aus.** FrameForge enthält eine 1000×1500 Pixel große Voreinstellung speziell für Pinterest-Pins. Die Abmessungen werden automatisch gesperrt.

**Schritt 4: Passen Sie den Zuschnitt an.** Ziehen Sie das Zuschneidefeld, um den gewünschten Teil des Bildes einzurahmen. Vorschau von Updates in Echtzeit.

**Schritt 5: Exportieren.** Klicken Sie auf Herunterladen. Das in der Größe geänderte Bild wird als PNG in Ihren Download-Ordner verschoben.

Das sind fünf Schritte ohne Anmeldung, ohne Hochladen und ohne Warten darauf, dass ein Server Ihr Bild verarbeitet. Alles geschieht in Ihrem Browser.

## Warum das für Pinterest-Ersteller wichtig ist

Pinterest-Ersteller müssen häufig Pins in großen Mengen produzieren – ein Bild für Ihr Pinterest-Board, eines für Ihren Blog-Beitrag, eines für X, eines für Instagram. Die Größenänderung jedes einzelnen Bildes an das falsche Format kostet Zeit und sieht im Feed unprofessionell aus.

Das voreingestellte System von FrameForge bedeutet, dass Sie die Plattform einmal auswählen und die Abmessungen automatisch festlegen. YouTube, Instagram, LinkedIn, Twitch und Pinterest verfügen alle über integrierte Voreinstellungen. Sie müssen sich nicht merken, ob es 1000×1500 oder 1000×1200 oder etwas anderes ist.

Wenn Sie eine andere Größe benötigen – zum Beispiel 1000×1200 für Vierkantstifte – können Sie in FrameForge benutzerdefinierte Abmessungen festlegen und diese als Ihre eigene Voreinstellung für das nächste Mal speichern.

## FAQ

**Was ist die ideale Pinterest-Pin-Größe?**
Pinterest empfiehlt 1000×1500 Pixel als ideales vertikales Pin-Verhältnis (2:3). Dieses Format wird optimal auf Mobil- und Desktop-Feeds angezeigt. Sie können auch 1000×1200 Pixel (Verhältnis 5:6) oder 1000×1300 Pixel verwenden – alle funktionieren gut, solange die Breite 1000 Pixel beträgt.

**Verfügt FrameForge über eine Pinterest-Voreinstellung?**
Ja. FrameForge enthält eine Voreinstellung für Pinterest-Pins mit 1000 x 1500 Pixeln. Öffnen Sie die Erweiterung, wählen Sie die Pinterest-Voreinstellung aus, passen Sie den Zuschnitt an und exportieren Sie. Kein Konto, kein Upload, kein Drittanbieterdienst.

**Kann ich die Größe auf andere Pinterest-Dimensionen ändern?**
Ja. Wenn Sie eine andere Größe benötigen, ermöglicht FrameForge benutzerdefinierte Abmessungen. Sie können jede gewünschte Breite und Höhe festlegen – zum Beispiel 1000×1200 für quadratische Pins oder 1200×900 für horizontale Pins, obwohl das vertikale Format auf Pinterest normalerweise am besten funktioniert.
