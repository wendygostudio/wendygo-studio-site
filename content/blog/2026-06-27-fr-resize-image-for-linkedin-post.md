# Comment redimensionner une image pour les publications LinkedIn dans Chrome (1200 × 627)

LinkedIn restitue les images de flux selon un recadrage horizontal étroit, similaire à X et Facebook. Les photos carrées perdent les bords verticaux. Les portraits sont compressés. Le correctif : publiez à 1 200 × 627 px (environ 1,9 : 1) et l'image s'affiche en intégralité dans l'aperçu du flux LinkedIn sans recadrage inattendu.

## Exigences de taille d’image LinkedIn

| Property | Value |
|----------|-------|
| Recommended size | 1200×627 px |
| Aspect ratio | ~1.9:1 (approximately 16:8.4) |
| Max file size | 10 MB (JPG/PNG) |
| Accepted formats | JPG, PNG, WebP |

## Pourquoi LinkedIn recadre les images

LinkedIn applique un recadrage central lors du rendu des images en ligne dans votre flux. La plate-forme affiche environ une tranche de 1,9 : 1 à partir du centre de tout ce que vous attachez.

Une photo carrée (1:1) à 1 200 × 1 200 est recadrée à environ 1 200 × 627, coupant les tiers supérieur et inférieur. Un portrait (9:16) est recadré au centre de manière encore plus agressive, ne montrant qu'une fine tranche verticale dans l'aperçu.

La publication à 1200×627 élimine la disparité. Votre image est déjà dans les bonnes proportions pour le flux LinkedIn, de sorte que l'aperçu montre la composition complète sans aucune découpe inattendue.

## Redimensionner pour LinkedIn avec FrameForge

1. **Installez FrameForge** — Téléchargez-le depuis le Chrome Web Store et épinglez-le à votre barre d'outils.
2. **Ouvrez votre image** — Cliquez sur l'icône FrameForge, puis cliquez sur **Ouvrir l'image** ou faites glisser et déposez votre fichier sur le canevas.
3. **Sélectionnez le préréglage LinkedIn** — Dans la liste déroulante **Plateforme**, sélectionnez **LinkedIn Post**. La toile se verrouille à 1200 × 627 px.
4. **Ajustez le recadrage** — Faites glisser la superposition de recadrage pour centrer votre sujet dans le cadre. Prévisualisez les deux modes de remplissage pour voir lequel convient le mieux à votre image.
5. **Exporter** — Cliquez sur **Exporter**. FrameForge enregistre l'image redimensionnée 1 200 × 627 dans votre dossier Téléchargements, prête à être téléchargée sur LinkedIn.

## Quel mode de remplissage pour LinkedIn ?

**Recadrer pour remplir** (Recommandé) — La totalité de la toile 1 200 × 627 est remplie ; l’excédent des côtés (pour les sources portrait) ou du haut/bas (pour les sources paysage) est coupé. Décidez exactement de ce qui reste dans le cadre en faisant glisser la superposition.

**Ajuster avec rembourrage** — L'image source complète est visible, avec des barres remplissant le cadre 1 200 × 627. Cela semble souvent involontaire dans un flux professionnel.

**Étirer pour remplir** — L'image se déforme horizontalement. Évitez à moins que la distorsion soit votre choix délibéré.

## LinkedIn par rapport aux autres plateformes

Si vous publiez sur plusieurs plateformes, FrameForge les gère toutes. LinkedIn (1200×627, 1,9:1) diffère légèrement de X/Twitter (1200×675, 16:9) et Instagram (1080×1080, 1:1). Vous pouvez exporter une version de LinkedIn, puis changer de préréglage pour les autres plateformes : même source d'image, exportations différentes, une extension.
