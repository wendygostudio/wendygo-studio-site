Les applications de productivité nécessitent souvent une connexion cloud : synchronisez vos sessions, suivez les statistiques sur tous les appareils, envoyez des notifications push sur votre téléphone. Mais une minuterie n’a besoin de rien de tout cela. Une véritable minuterie Pomodoro hors ligne s'exécute entièrement dans votre navigateur : pas d'Internet, pas de connexion, aucune donnée envoyée nulle part.

Cela est important lorsque vous :

- **Travail à distance dans des endroits sans Wi-Fi fiable** : un café, une bibliothèque ou un espace de coworking
- **Voyage** : en avion, en train ou en voiture avec une connectivité limitée
- **Préoccupé par la confidentialité** : vous ne voulez pas que les données de focus soient synchronisées avec un serveur cloud
- **Travailler hors ligne par choix** — la déconnexion comme stratégie privilégiée

## Pourquoi le mode hors ligne est important pour la concentration

La plupart des extensions de navigateur demandent une connexion Internet pour vérifier votre session, envoyer des analyses ou synchroniser des séquences. Cela crée des frictions : si le WiFi tombe, votre session est interrompue. Si les serveurs de l'entreprise tombent en panne, votre minuterie se met en panne. Une extension hors ligne supprime cette dépendance.

Une minuterie hors ligne signifie également que vos sessions de concentration restent privées : aucune entreprise ne sait quand vous travaillez, combien de temps vous vous concentrez ou quelles sont vos habitudes. Les données restent sur votre appareil, point final.

## Ce dont une minuterie hors ligne a besoin

Une bonne minuterie Pomodoro hors ligne devrait inclure :

- **Durées de session configurables** — 15, 25, 45, 60 minutes (un travail différent nécessite un rythme différent)
- **Suivi des pauses** : courtes pauses entre les sessions, pauses plus longues toutes les N sessions
- **Persistance** — vos séquences et votre nombre de sessions restent même après la fermeture du navigateur
- **Retour visuel et audio** : notification claire lorsque le temps est écoulé, que l'onglet soit ciblé ou non
- **Aucune dépendance cachée** — le minuteur fonctionne dès que vous l'installez
