Eine UUID ist eine standardisierte Kennung für Testdaten, Datensätze und Referenzen. Mit [TextForge](/de/textforge/) erzeugst und kopierst du UUIDs lokal. Prüfe das Zielformat, wenn eine API eine bestimmte Version verlangt. UUIDs identifizieren Objekte, ersetzen aber keine Zugangsdaten oder Berechtigungsprüfung.
