# Tamanho da capa do perfil do Pinterest: guia 800×450 e 16:9

A capa do perfil do Pinterest é a imagem horizontal no topo de um perfil empresarial. Tem uma função diferente da de um pin: a capa apresenta o perfil, enquanto o pin é conteúdo que as pessoas descobrem, guardam e visitam. Manter os dois formatos separados evita usar o recorte errado.

## O que o Pinterest recomenda oficialmente

A [página de ajuda do Pinterest sobre a capa do perfil](https://help.pinterest.com/en/business/article/personalize-your-profile) indica que esta função está disponível para uma **conta empresarial do Pinterest**. A imagem deve ter pelo menos **800×450 píxeis** e o Pinterest recomenda uma proporção horizontal de **16:9**. Também indica que qualquer pessoa no Pinterest pode ver o perfil, por isso trate a capa como uma imagem pública.

Estes são os requisitos e a recomendação publicados pela plataforma. Não garantem que todos os ecrãs mostrem exatamente os mesmos píxeis. Mantenha o logótipo, produto ou mensagem curta importante afastado dos limites para continuar visível depois de um recorte responsivo.

## Mantenha o conteúdo importante numa zona segura

Use uma tela 16:9 para o fundo e coloque o motivo principal perto do centro visual. É uma regra prática de composição, não uma medida adicional publicada pelo Pinterest.

- Deixe espaço à volta de rostos, logótipos e textos curtos.
- Não encoste os detalhes essenciais aos limites superior, inferior ou laterais.
- Prefira uma imagem simples e com bom contraste, legível num ecrã estreito.
- Veja o recorte num ecrã grande e numa pré-visualização móvel.
- Não coloque um design completo de pin dentro da capa; as proporções são diferentes.

Se a fonte for pequena, aumentá-la não recupera os detalhes perdidos. Quando possível, comece com uma imagem nítida de pelo menos 800×450 píxeis. Uma tela de trabalho 16:9 maior é uma escolha prática, não um mínimo oficial.

## Redimensione uma capa localmente no Chrome

1. **Escolha uma tela 16:9.** Defina dimensões personalizadas de pelo menos 800×450 píxeis.
2. **Abra a imagem no FrameForge.** A extensão prepara a imagem no navegador em vez de a enviar para um serviço de redimensionamento.
3. **Posicione o ponto focal.** Mantenha o rosto, logótipo ou motivo afastado dos limites.
4. **Verifique o recorte.** Reduza a pré-visualização e confirme que o motivo continua reconhecível.
5. **Exporte antes de carregar.** Guarde o resultado e use o editor de capa do Pinterest para o ajuste final.

O FrameForge é útil para repetir um recorte local ao preparar várias imagens de marca ou de perfil. Verifique a ficha e as permissões atuais de qualquer extensão antes de a instalar.

## Não confunda a capa com um pin do Pinterest

O [guia do tamanho dos pins do Pinterest](/pt/blog/resize-image-for-pinterest-pin/) trata do formato vertical de conteúdo. Na [orientação de distribuição dos pins](https://help.pinterest.com/en/business/article/pin-performance-and-distribution), o Pinterest recomenda uma proporção 2:3 para imagens e vídeos Pin de 15 a 60 segundos, enquanto a capa do perfil usa 16:9. Escolha a tela de acordo com a superfície onde vai publicar.

## Perguntas frequentes

### Que tamanho deve ter uma capa de perfil do Pinterest?

Para um perfil empresarial, a imagem deve ter pelo menos 800×450 píxeis. O Pinterest recomenda uma proporção horizontal de 16:9. São as orientações publicadas para a capa, não uma garantia de recorte igual em todos os dispositivos.

### A capa do perfil do Pinterest é o mesmo que um pin?

Não. A capa pertence ao perfil empresarial. Um pin é conteúdo separado, com formatos, zonas seguras e metadados próprios. Use 16:9 para a capa e um formato vertical para o pin.

### Posso preparar uma capa do Pinterest sem a carregar?

Sim. O FrameForge pode recortar e redimensionar a imagem local no Chrome, exportar o resultado e deixar o carregamento final para o Pinterest.
