# Comment redimensionner une image pour les publications Instagram dans Chrome (1080 × 1080)

Votre téléphone déclenche à 9h16. Le flux d'Instagram est par défaut au format carré 1:1. C'est dans cet espace que les photos de portraits sont mutilées : des visages coupés au niveau du front, des détails importants poussés vers le bord ou l'image entière pressée dans une vilaine boîte aux lettres.

Le résoudre ne devrait pas nécessiter Photoshop ni télécharger votre photo sur un site tiers. FrameForge est une extension Chrome qui redimensionne entièrement les images dans votre navigateur : pas de téléchargement, pas de compte, pas d'attente de serveur.

## Exigences de taille d'image Instagram

| Format | Dimensions | Aspect ratio |
|--------|-----------|--------------|
| Square post | 1080×1080 px | 1:1 |
| Portrait post | 1080×1350 px | 4:5 |
| Landscape post | 1080×566 px | 1.91:1 |
| Minimum width | 1080 px | — |
| Max file size | 8 MB | — |
| Formats | JPG, PNG | — |

Instagram compresse les images lors du téléchargement, alors commencez par la version de la plus haute qualité dont vous disposez. Travailler à partir d'une source compressée ou basse résolution semblera nettement pire une fois que la propre compression d'Instagram sera appliquée dessus.

## Pourquoi utiliser une extension de navigateur plutôt qu'un outil en ligne

Les redimensionneurs Web – Canva, Adobe Express, Squoosh – fonctionnent, mais ils téléchargent tous votre image sur un serveur distant. Pour les photos personnelles, le travail de client ou tout ce que vous préférez garder privé, c'est un véritable compromis.

**FrameForge reste local.** Il fonctionne comme une extension Chrome et traite votre image en utilisant les ressources de votre propre machine. Rien n'est envoyé à un serveur, pas même pour la télémétrie. Il n'y a aucun compte à créer et aucune limite de taille de fichier imposée par un quota backend.

Il fonctionne également plus rapidement que les outils Web pour les fichiers volumineux, car il n'y a pas de latence de téléchargement à attendre.

## Étape par étape : redimensionner pour Instagram avec FrameForge

1. **Installez FrameForge** — Installez à partir du Chrome Web Store et épinglez l'icône sur votre barre d'outils à partir du menu Extensions.
2. **Ouvrez votre image** — Cliquez sur l'icône FrameForge, puis cliquez sur Ouvrir l'image ou faites glisser votre fichier directement sur le canevas.
3. **Sélectionnez le préréglage Instagram Post** — Dans la liste déroulante Plateforme, sélectionnez Instagram Post. La toile se verrouille à 1080 × 1080 px avec un rapport 1:1.
4. **Ajustez le recadrage** — Faites glisser la superposition de recadrage pour centrer votre sujet. Basculez entre les modes de remplissage pour comparer la façon dont chacun gère votre image spécifique.
5. **Exporter** — Cliquez sur Exporter. FrameForge enregistre l'image 1080 × 1080 dans votre dossier Téléchargements, prête à être téléchargée.

## Gestion des photos de portrait et de paysage

La plupart des publications Instagram commencent sous forme de photos de téléphone verticales – au format 9:16 entrant dans un cadre carré 1:1. FrameForge vous propose trois façons de gérer cela :

**Recadrer pour remplir** (recommandé) : le cadre est complètement rempli. L'excédent du haut et du bas est recadré. Faites glisser la superposition pour décider ce qui reste dans le cadre, généralement centré sur le visage du sujet ou sur le visuel clé.

**Ajuster avec rembourrage** : l'intégralité de l'image est visible, mais des barres horizontales apparaissent sur les côtés. Peut sembler intentionnel si les barres sont d’une couleur délibérée, mais se lit généralement après coup sur Instagram.

**Étirer pour remplir** : L'image est déformée horizontalement pour remplir le cadre. Cela a presque toujours l’air mauvais – évitez-le à moins que la distorsion ne soit un choix stylistique délibéré.

Pour les photos de paysage (large) allant dans un carré : l'excédent se trouve plutôt à gauche et à droite. La même logique s'applique : recadrez pour remplir et ajustez la superposition pour garder le sujet principal centré.

## Quel format de publication Instagram devriez-vous choisir ?

Les trois formats fonctionnent sur Instagram, mais ils ont des comportements différents dans le flux :

**Carré (1:1)** est le choix le plus sûr. Il fonctionne de manière cohérente dans la vue grille, la page d'exploration et le flux d'accueil. Si vous publiez simultanément sur plusieurs plates-formes, le recadrage carré est le plus portable.

**Le portrait (4:5)** occupe plus d'espace vertical dans le flux : environ 20 % d'espace d'écran en plus qu'un carré. Pour les photos déjà verticales, ce format vous permet d'afficher une plus grande partie de l'image sans recadrer de manière aussi agressive. FrameForge peut gérer cela avec un ratio de recadrage personnalisé.

**Paysage (1,91:1)** convient aux prises de vue panoramiques et aux compositions larges. Il affiche moins d'image dans l'aperçu du flux, mais peut bien fonctionner pour les scènes où la largeur compte plus que la hauteur.

## Redimensionnement pour plusieurs plates-formes

Si vous publiez le même contenu sur YouTube, Twitch ou X, FrameForge inclut des préréglages pour chacun d'entre eux. Vous pouvez redimensionner la même image source selon différentes dimensions de plate-forme sans changer d'outil, ce qui est utile pour les flux de travail par lots lors de la publication sur plusieurs canaux le même jour.

## Foire aux questions

**Quelle est la taille d'image correcte pour une publication Instagram ?**
1080×1080 px pour un post carré (rapport 1:1). Instagram prend également en charge le portrait (1080×1350, 4:5) et le paysage (1080×566, 1,91:1). Square est le plus sûr si vous ne savez pas lequel utiliser.

**FrameForge télécharge-t-il mes images sur un serveur ?**
Non. FrameForge traite tout localement dans votre navigateur. Rien n'est téléchargé et aucun compte n'est requis.

**Que faire si ma photo est en orientation portrait (verticale) ?**
Utiliser le recadrage pour remplir — FrameForge vous permet de faire glisser la superposition de recadrage pour conserver la partie importante de votre photo dans le cadre 1080 × 1080, en coupant le haut et le bas.

**Puis-je utiliser FrameForge pour d'autres plateformes ?**
Oui. Il comprend des préréglages pour les vignettes YouTube (1280 × 720), les panneaux Twitch et les tailles de publication X (Twitter), afin que vous puissiez redimensionner la même image pour différentes plates-formes sans changer d'outil.

**FrameForge est-il gratuit ?**
Oui – installation gratuite avec redimensionnement principal et préréglages de plate-forme inclus. Une mise à niveau Pro ajoute la superposition de texte et le traitement par lots.
