# Estensione Chrome Convertitore file locale: immagini, audio, documenti: nessun caricamento

La maggior parte dei convertitori online prende il tuo file, lo invia a un server, lo elabora lì e restituisce un risultato. La tua foto, documento o foglio di calcolo vive brevemente nell'infrastruttura di qualcun altro. ConvertForge converte i file interamente all'interno del tuo browser: nulla lascia la tua macchina.

## Cosa converte ConvertForge

ConvertForge è un router di conversione universale con un'interfaccia drag-and-drop. Rilascia un file e rileva automaticamente il tipo:

- **Immagini**: HEIC da iPhone e altri formati di immagine, convertiti localmente senza servizio cloud
- **Audio**: estrae l'audio da file video o converte tra formati audio
- **Documenti**: OCR locale utilizzando Tesseract, estraendo testo da PDF e immagini sul dispositivo
- **Dati**: conversione tra JSON, CSV, YAML e XLSX per pipeline di dati o importazioni di fogli di calcolo

## Come convertire un file localmente

1. Installa ConvertForge dalla pagina ConvertForge: nessun account, nessuna registrazione
2. Fai clic sull'icona ConvertForge nella barra degli strumenti di Chrome per aprirla come pannello locale
3. Trascina e rilascia il tuo file sul router universale
4. ConvertForge rileva il tipo di file e mostra i formati di output disponibili
5. Seleziona il formato di destinazione e converti: il file verrà scaricato direttamente sul tuo dispositivo

Tutta l'elaborazione utilizza API native del browser: Tesseract per OCR, WebAssembly per l'elaborazione di audio e immagini.

## Locale vs. Cloud: cosa cambia

| Feature | Cloud converter | ConvertForge |
|---------|----------------|--------------|
| File leaves your machine | Yes | No |
| Works offline | No | Yes |
| File size limits | Often (10–25 MB) | None (RAM-bound) |
| Account required | Usually | No |
| Works from browser | Yes | Yes |

Se gestisci foto con dati di posizione EXIF, documenti con informazioni personali o file di dati proprietari, la differenza tra cloud e locale non è solo comodità: è un limite di privacy.

## Domande frequenti

**ConvertForge carica i miei file su qualsiasi server?**
No. ConvertForge viene eseguito interamente nel tuo browser utilizzando le API del browser e WebAssembly. Niente viene caricato sui server di Wendygo Studio o su terze parti.

**Funziona offline?**
SÌ. Poiché l'elaborazione è locale, ConvertForge funziona completamente offline una volta installato: su un aereo, senza Wi-Fi o su un computer con accesso di rete limitato.

**È gratuito?**
ConvertForge ha un livello gratuito senza account richiesto. Visita la pagina ConvertForge per i prezzi attuali.

**In cosa differisce dai convertitori online?**
I convertitori online caricano il tuo file su un server remoto e lo elaborano lì. ConvertForge fa tutto questo nel tuo browser: il tuo file non lascia mai il tuo computer.
