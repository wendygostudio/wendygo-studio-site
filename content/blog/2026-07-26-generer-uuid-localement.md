Un UUID est un identifiant standardisé utile pour les tests, enregistrements et références. Avec [TextForge](/fr/textforge/), générez et copiez des UUID localement. Vérifiez le format lorsqu'une API exige une version précise. Un UUID identifie un objet ; il ne remplace pas les identifiants ni un contrôle d'accès.
