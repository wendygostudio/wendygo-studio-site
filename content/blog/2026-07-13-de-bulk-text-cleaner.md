# Bulk Text Cleaner: Verarbeiten und transformieren Sie große Textmengen in Chrome

Wenn Sie eine Kontaktliste exportieren, Protokollzeilen abrufen oder eine Webseite durchsuchen, sind die Rohdaten selten sauber. Sie müssen Duplikate entfernen, zusätzliche Leerzeichen entfernen, die Zeilen sortieren und vielleicht nur die E-Mails extrahieren – alles auf einmal. Mit TextForge können Sie diese Vorgänge in einem einzigen Rezept verketten, das lokal in Ihrem Browser ausgeführt wird.

## Allgemeine Massenreinigungsvorgänge

TextForge umfasst 58 Textfunktionen. Am nützlichsten für die Massenverarbeitung:

- **Doppelte Zeilen entfernen** – Deduplizieren Sie eine Liste mit einem Klick
- **Leerzeichen entfernen** – Entfernen Sie führende/nachgestellte Leerzeichen aus jeder Zeile
- **Zeilen von A–Z sortieren** – Sortieren Sie jede Liste alphabetisch
- **Leerzeilen entfernen** – Leere Zeilen aus der Ausgabe löschen
- **E-Mails extrahieren** – Ziehen Sie jede E-Mail-Adresse aus einem unordentlichen Textblock heraus
- **URLs extrahieren** – Isolieren Sie jede URL aus Absätzen oder Protokollen
- **Groß-/Kleinschreibung umwandeln** – Inkonsistente Groß- und Kleinschreibung über alle Zeilen hinweg normalisieren
- **Base64-Kodierung/-Dekodierung** – Forge Magic erkennt Base64 beim Einfügen automatisch

## Verketten Sie Vorgänge zu einem wiederverwendbaren Rezept

Erstellen Sie die Kette einmal – Leerzeichen entfernen → Leere Zeilen entfernen → Doppelte Zeilen entfernen → Zeilen von A–Z sortieren – speichern Sie sie als benanntes Rezept und führen Sie die gesamte Pipeline beim nächsten Mal mit einem Klick aus. Für unbegrenzt gespeicherte Rezepte ist die Pro-Version erforderlich.

## Beispiel: Bereinigen eines CRM-Datenexports

Sie exportieren E-Mail-Adressen aus einem CRM. Die Rohausgabe enthält zusätzliche Leerzeichen, Duplikate, Leerzeilen und gemischte Großschreibung. Wenden Sie das Rezept an: Leerzeichen entfernen → Kleinbuchstaben → Leerzeilen entfernen → Doppelte Zeilen entfernen → Zeilen von A–Z sortieren. Ein Klick nach der Einrichtung.

## So richten Sie Ihren Massenreinigungs-Workflow ein

1. Öffnen Sie TextForge und fügen Sie Ihren Rohtext ein
2. Wählen Sie Ihre Reinigungsfunktionen nacheinander aus und wenden Sie sie an
3. Speichern Sie die Sequenz als benanntes Rezept
4. Kopieren Sie die saubere Ausgabe – alles lief lokal

## FAQ

**Ladet TextForge meinen Text auf einen Server hoch?**
Nein. Die gesamte Verarbeitung erfolgt lokal in Ihrem Browser. Ihre Daten verlassen niemals Ihren Computer.

**Wie viele Zeilen kann TextForge gleichzeitig verarbeiten?**
Durch die Erweiterung wird kein festes Limit erzwungen. Bei typischer Nutzung werden Tausende von Leitungen sofort verarbeitet.

**Kann ich einen Reinigungsworkflow speichern, um ihn wiederzuverwenden?**
Ja. Verknüpfen Sie Funktionen mit einem benannten Rezept und führen Sie es mit einem Klick aus. Für unbegrenzte Rezepte ist Pro erforderlich.

**Welche Textarten kann ich mit TextForge massenbereinigen?**
CRM-Exporte, Tabellenspalten, Protokolldateien, API-Antworten, E-Mail-Listen, URL-Sammlungen, Code-Snippets – jeder reine Text.
